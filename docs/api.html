API Reference

Complete reference for the agentevals public API.

evalite(name, fn) / evalite(name, options, fn)

Define a single eval task. The callback receives an EvalContext with an expect function.

evalite('task name', async ({ expect }) => {
  // call AI SDK, then assert
})

evalite('task name', { judge: model, timeout: 30000 }, async ({ expect }) => {
  // with options
})
OptionTypeDescription
judgeLanguageModelModel to use for toPassJudge() assertions
timeoutnumberTimeout in milliseconds

Aliases: test and it are identical to evalite.

evalite.group(name, fn) / evalite.group(name, options, fn)

Group related evals together. Options propagate to child evals.

evalite.group('group name', () => {
  evalite('task 1', async ({ expect }) => { /* ... */ })
  evalite('task 2', async ({ expect }) => { /* ... */ })
})

evalite.group('group name', {
  judge: anthropic('claude-sonnet-4-20250514'),
  timeout: 30000,
}, () => {
  // all evals here inherit the judge and timeout
})
OptionTypeDescription
judgeLanguageModelDefault judge model for evals in this group
timeoutnumberDefault timeout for evals in this group

expect(result)

Create assertions on an AI SDK result (GenerateTextResult or awaited StreamTextResult).

MethodDescription
.toContain(text, opts?)Output contains text. Case-insensitive by default. Pass { caseSensitive: true } for exact match.
.toMatch(pattern)Output matches a regex or string pattern.
.toAskQuestions(opts?)Output contains N question marks. Options: { min, max }.
.toPassJudge(criteria)LLM judge evaluates if output meets criteria. Async. Accepts string or { criteria, threshold, judge }.
.to(graderFn)Custom grader function. Can be sync or async.
.not.*Negate any assertion.
.toolCalls.*Access tool call assertions (see below).

All assertions are fluent-chainable:

expect(result)
  .toContain('hello')
  .toMatch(/greeting/i)
  .not.toContain('error')

expect(result).toolCalls

Assertions for tool call behavior.

MethodDescription
.toHaveBeenCalled()At least one tool was called.
.toInclude(name)A specific tool was called.
.toHaveCallCount(n)Total number of tool calls.
.toHaveCallCount(name, n)Call count for a specific tool.
.toHaveArgs(name, args)Tool was called with specific arguments. Supports matchers.
.toHaveResult(name, result)Tool returned a specific result.
.getCalls(name?)Get raw call data (non-asserting).
.not.*Negate any tool call assertion.

matchers

Flexible matchers for use with toHaveArgs and toHaveResult.

MatcherDescription
matchers.objectContaining(obj)Partial object match.
matchers.arrayContaining(arr)Array contains all specified elements.
matchers.stringMatching(pattern)String matches regex or string pattern.
matchers.anything()Matches any value.

Tool Testing Helpers

createMockExecutor(returnValue)

Creates an executor that records calls and returns a fixed value.

const mock = createMockExecutor({ temperature: 72 })
// Use as execute function in AI SDK tool()
// After eval: mock.calls => [{ location: 'Tokyo' }, ...]

createSpyExecutor(fn)

Wraps a real executor and records calls + results.

const spy = createSpyExecutor(async ({ location }) => fetchWeather(location))
// After eval: spy.calls, spy.results

defineGrader(name, fn)

Create a reusable grader function for use with expect(result).to(grader).

const noPII = defineGrader('noPII', (result) => {
  const hasPII = /\b\d{3}-\d{2}-\d{4}\b/.test(result.text)
  return {
    pass: !hasPII,
    reason: hasPII ? 'Contains PII' : 'No PII detected',
  }
})

expect(result).to(noPII)

The grader function receives an AIResult and returns { pass: boolean, reason: string, score?: number }. Can be async.

Configuration

Create agentevals.config.ts in your project root:

import { defineConfig } from '@nem035/agentevals'

export default defineConfig({
  include: ['**/*.eval.ts'],
  exclude: ['node_modules/**'],
  trials: 1,
  timeout: 60000,
  parallel: true,
  maxConcurrency: 5,
  reporters: ['console'],
  maxCost: 10.0,
})
OptionTypeDefaultDescription
includestring[]['**/*.eval.ts', ...]Glob patterns for eval files
excludestring[]['node_modules', ...]Glob patterns to exclude
trialsnumber1Times to run each eval
timeoutnumber60000Default timeout in ms
parallelbooleantrueRun evals in parallel
maxConcurrencynumber5Max concurrent evals
reportersstring[]['console']'console' or 'json'
maxCostnumberundefinedMax cost in USD before stopping

CLI Reference

# Run all evals
agentevals run

# Run specific file
agentevals run my-agent.eval.ts

# Filter by task name
agentevals run --grep "greeting"

# JSON output for CI
agentevals run --reporter=json

# Stop if cost exceeds $1
agentevals run --max-cost=1.00

# Run each task 5 times
agentevals run --trials=5

# See what would run without executing
agentevals run --dry-run

# Create config and example files
agentevals init

CI/CD Integration

agentevals returns exit code 1 when tests fail.

# .github/workflows/evals.yml
name: Evals
on: [push]

jobs:
  eval:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20

      - run: npm install
      - run: npx agentevals run --reporter=json --max-cost=5.00
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
