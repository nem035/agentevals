agentevals

Test your AI apps like you test your code. A lightweight eval framework built on top of the AI SDK.

Cookbook API Reference GitHub
npm install @nem035/agentevals

Quick Start

Create a .eval.ts file and start testing.

// my-agent.eval.ts
import { evalite } from '@nem035/agentevals'
import { anthropic } from '@ai-sdk/anthropic'
import { generateText } from 'ai'

evalite('answers questions', async ({ expect }) => {
  const result = await generateText({
    model: anthropic('claude-sonnet-4-20250514'),
    system: 'You are a helpful assistant.',
    prompt: 'What is 2 + 2?',
  })

  expect(result).toContain('4')
})

Run it:

$ npx agentevals run

Features

AI SDK Native

No wrapper layer. Use generateText, streamText, and tool from the ai package directly.

Streaming Support

Test streaming responses by awaiting streamText results. All properties resolve automatically.

LLM-as-Judge

Use any model as a judge for nuanced evaluations that simple string matching can't handle.

Tool Call Testing

Assert tools were called, check arguments with matchers, verify results. Mock and spy executors included.

Simple Assertions

toContain, toMatch, toPassJudge, custom graders. Fluent chaining with .not negation.

CLI

Discover and run *.eval.ts files with configurable trials, concurrency, cost limits, and reporters.

A Taste of agentevals

Group related evals, use LLM-as-judge for nuanced criteria, test tool calls with matchers.

Grouping + LLM-as-Judge

import { evalite } from '@nem035/agentevals'
import { anthropic } from '@ai-sdk/anthropic'
import { generateText } from 'ai'

evalite.group('customer-service', {
  judge: anthropic('claude-sonnet-4-20250514'),
}, () => {

  evalite('handles complaints', async ({ expect }) => {
    const result = await generateText({
      model: anthropic('claude-sonnet-4-20250514'),
      system: 'You are a customer service agent.',
      prompt: 'Your product broke after one day!',
    })

    await expect(result).toPassJudge(
      'Acknowledges frustration and offers a clear resolution'
    )
  })

})

Tool Call Testing

import { evalite, createMockExecutor, matchers } from '@nem035/agentevals'
import { generateText, tool } from 'ai'
import { z } from 'zod'

evalite('uses weather tool', async ({ expect }) => {
  const mock = createMockExecutor({ temp: 72 })

  const result = await generateText({
    model: anthropic('claude-sonnet-4-20250514'),
    prompt: 'Weather in Tokyo?',
    tools: {
      getWeather: tool({
        description: 'Get weather',
        parameters: z.object({ location: z.string() }),
        execute: mock,
      }),
    },
    maxSteps: 3,
  })

  expect(result).toolCalls.toInclude('getWeather')
  expect(result).toolCalls.toHaveArgs('getWeather', {
    location: matchers.stringMatching(/tokyo/i),
  })
})
